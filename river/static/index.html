Settings

The most specific value wins: item, then agent, then project, then global, then the built-in default.
launch_agents lists the agents the Start button offers, as Label=command entries separated by ;. The first is the default. @claude-code and @codex are launch profiles: MaximizePM builds the command from their options, the claude_* and codex_* settings (Remote Control, permission or sandbox mode, more arguments, the first prompt; the setup guide has toggles for them). @codex sandbox=read-only sets an option for that entry alone. For example: Claude Code=@claude-code; Plan first=@claude-code permission_mode=plan; Codex=@codex; Grok=grok "run maxpm go in this folder and follow the briefing". Any other command is custom: {model} and {effort} take the launch dialog's choice, and with no choice the flag before them drops out.
